STM32 & Arduino Embedded Systems
This repository contains embedded system projects focusing on sensor integration, data acquisition, and real-time control using STM32 and Arduino microcontrollers.

Key Features & Skills Demonstrated:

Hardware Integration: Interfacing with environmental sensors and I2C/SPI LCD modules.

Embedded Programming: Developing efficient C/C++ code for real-time hardware manipulation.

System Architecture: Utilizing STM32 and Arduino architectures for optimal hardware-software synergy.

(Note: Source codes, scripts, and circuit diagrams are actively being documented and uploaded.)
